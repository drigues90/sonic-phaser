## 🎮 Sobre o Projeto

Este projeto visa recriar a experiência autêntica do Sonic the Hedgehog de 8-bit do Master System (1991), incluindo:

- 6 Zonas completas com 3 atos cada
- Física fiel ao jogo original
- Sistema de inimigos (Badniks) e power-ups
- Chaos Emeralds escondidos nos níveis
- Fases especiais estilo pinball
- Suporte para controles touch (mobile)
- Exportação nativa para Android

## 🚀 Início Rápido

### Pré-requisitos
- Node.js 14+
- npm ou yarn

### Instalação
```bash
# Clone o repositório
git clone https://github.com/drigues90/sonic-phaser.git
cd sonic-phaser

# Instale as dependências
npm install

# Execute em modo desenvolvimento
npm run dev
```

### Build para Produção
```bash
# Build web
npm run build

# Build e sync para Android
npm run cap:sync

# Abrir no Android Studio
npm run cap:android
```
